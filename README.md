# Job Research

پایهٔ برنامهٔ جستجوی شغل برای نقش‌های فنی Senior DevOps، Platform و SRE با هدف ریلوکیشن.

## وضعیت فعلی

این نسخه فقط اتصال قابل تنظیم به مدل و تولید پیش‌نویس ایمیل را پیاده می‌کند.
جستجوی سایت‌ها، زمان‌بندی، پایگاه داده و ارسال ایمیل هنوز پیاده نشده‌اند.
هیچ رزومه یا اطلاعات محرمانه‌ای در مخزن قرار ندارد.

## اجرا

Python 3.10+؛ این مرحله وابستگی خارجی ندارد.

```bash
cp .env.example .env
python model_client.py --profile data/profile.json --job data/job.txt
```

پوشهٔ data را بسازید؛ profile.json شامل اطلاعات واقعی و تأییدشدهٔ رزومه و
job.txt متن آگهی باشد. خروجی، JSON دارای subject و body است و ایمیلی ارسال نمی‌شود.

## اتصال به مدل

LLM_BASE_URL آدرس پایهٔ سرویس شامل مسیر /v1 است؛ IP، پورت و مسیر
همگی قابل تغییرند. LLM_MODEL نام دقیق مدل ارائه‌شده در سرویس است.
LLM_API_KEY برای سرویس‌هایی که احراز هویت دارند تنظیم می‌شود.

برای vLLM آدرس سرویس خودتان را وارد کنید.
برای OpenRouter آدرس پایه https://openrouter.ai/api/v1 است؛ کلید و شناسهٔ
مدل باید متعلق به همان سرویس باشند. برای سایر سرویس‌ها نیز API سازگار
با Chat Completions لازم است. تغییر سرویس صرفاً با تغییر تنظیمات انجام می‌شود.
سرویس‌های دارای پروتکل متفاوت به adapter جدا نیاز دارند.

خطا، پاسخ ناقص و JSON نامعتبر به‌عنوان شکست گزارش می‌شود؛ تغییر خودکار به
سرویس پولی وجود ندارد. بررسی انسانی متن پیش از استفاده، برای اطمینان از
درستی سوابق لازم است؛ این مرحله فقط تولید پیش‌نویس است.

## مراحل بعدی

- منابع مجاز جستجو و استخراج آگهی، با ثبت لینک و تاریخ.
- فیلتر عنوان فنی، کشور و زبان انگلیسی؛ حقوق قابل مذاکره.
- بررسی جداگانهٔ شواهد حمایت از ویزا و کمک ریلوکیشن؛ موارد مبهم برای بررسی.
- ثبت پایدار آگهی، صف و سابقهٔ درخواست برای جلوگیری از ارسال تکراری.
- اجرای ساعتی و سقف قابل تنظیم؛ مقدار پیشنهادی اولیه پنج ارسال در روز.
- ارسال با ایمیل استخدامی مستند یا مسیر رسمی درخواست؛ بدون حدس آدرس ایمیل.

مقادیر SEARCH_INTERVAL_SECONDS، DAILY_EMAIL_LIMIT و SEND_EMAILS در نمونهٔ
تنظیمات برای مراحل بعدی رزرو شده‌اند و در نسخهٔ فعلی اثری ندارند.
